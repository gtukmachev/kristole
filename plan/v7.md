## Улучшения

### 1. Сохранение игрока между посещениями сайта (без бэкенда)

- Состояние игрока сохраняется между посещениями сайта. Используем **базу данных браузера** (IndexedDB).
- **Список игроков** в базе. Отдельного экрана выбора игрока не делаем.
- **Ключ игрока — его имя в нижнем регистре.** Ввёл имя, которое уже есть, — загрузились его данные из базы.
- **Переименование = выбор или создание игрока:** новое имя, которого нет в базе, создаёт нового игрока; имя, которое есть, — переключает на него.
- **Таблицу рекордов** тоже храним в этой базе.
- Пока всё без бэкенда: данные живут только в этом браузере.

## Решения (обсуждены 23.11.2026 для v5, перенесены в v7)

- **У игрока сохраняется** его прогресс: открытые главы.
- **Лучший счёт и таблица рекордов — общие на всю игру**, от игрока не зависят. Хранятся в той же базе браузера.
- **Незаконченный забег сохраняется** после каждого пройденного уровня: глава, следующий уровень, очки, здоровье, перки, оружие.
  - В меню появляется кнопка **«Continue»**: начать сразу со следующего уровня.
  - Сохранение у каждого игрока своё.
- **Старые данные из localStorage:** рекорды переходят в общую таблицу, открытые главы — текущему игроку.
- **Имена:**
  - пробелы по краям убираются автоматически;
  - пробелы внутри имени заменяются на тире (`big leo` → `big-leo`);
  - ключ игрока — имя в нижнем регистре.
