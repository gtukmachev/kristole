# Идеи на будущие версии

Сюда записываем идеи, которые **пока не планируем делать**.

- Каждая группа идей — своя папка: **буква и короткая тема**, например `A-mobile`. Внутри — `README.md` с идеями.
- Буквы (A, B, C…) — чтобы не путать с номерами настоящих версий.
- Новая идея — в подходящую папку или в новую со следующей буквой.
- Когда решим делать группу, она получает номер: создаём `plan/vN.md`, переносим туда её идеи и обсуждаем перед началом работы.
- Последняя выпущенная версия: v8 (`plan/v8.md`, игра на телефоне и планшете в браузере).

## Группы

- [A-mobile](A-mobile/README.md) — управление на телефоне и планшете.
- [B-menu](B-menu/README.md) — меню и управление игрой.
