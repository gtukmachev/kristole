# Фаза «Публикация и монетизация»

Это отдельная фаза роудмэпа, а не очередная версия игры. **Пока мы её не делаем, только собираем идеи (брейншторм).**
Идёт параллельно с разработкой и с ней не смешивается: версии игры живут в `plan/vN.md`, всё о публикации — здесь.

Каждая тема — отдельный файл. Новые идеи дописываются в подходящий файл или в новый.

| Файл | Тема |
|---|---|

## Цель

Первый проект, который Григорий публикует сам. В первую очередь это тренировка. Проект маленький и простой, но если людям понравится — можно немного заработать.
